# Desktop App Cloner

Run separate accounts of your desktop apps side by side on Windows: Claude, ChatGPT, Discord, VS Code, Cursor, Windsurf, Chrome, Edge, Brave and more. Each clone has its own sign-in, its own name and color, and its own desktop shortcut.

## Download

1. Open the **[latest release](https://github.com/yassirabidy/desktop-app-cloner-releases/releases/latest)**.
2. Under **Assets**, download **`DesktopAppCloner-<version>-Setup.exe`**.
3. Double-click it. It installs for your Windows user (no admin needed), adds Start menu and desktop shortcuts, and opens the app.

The other files in a release (`latest.yml` and the `.blockmap`) are used by the app to update itself; you don't need to download them.

**"Windows protected your PC"?** The app is not code-signed yet, so Windows SmartScreen may warn about it the first time. Click **More info › Run anyway**. Only do this for files downloaded from this page.

## Requirements

- Windows 10 or 11.
- The apps you want to clone, already installed.

## Updates

The app updates itself from this page. A new version downloads in the background and installs when you close the app, or right away if you click **Restart**. Your clones, their sign-ins and their shortcuts are kept.
